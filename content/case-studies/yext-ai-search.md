## The plugin

Yext AI Search is a free plugin in the WordPress.org plugin directory. It connects a WordPress site to Yext search. A Yext account is required.

The listing says the plugin can:

- Index WordPress content into Yext with pre-built connectors.
- Run scheduled syncs, so search results stay current.
- Let site owners style the search bar with a live editor, with no code.
- Add the search experience to any page with Gutenberg blocks.
- Replace the native WordPress search in one step.

The listing gives these facts: version 1.0.7, added to the directory in February 2022, needs WordPress 5.8 or later and PHP 7.4 or later.

Listing: [wordpress.org/plugins/yext-ai-search](https://wordpress.org/plugins/yext-ai-search/)
